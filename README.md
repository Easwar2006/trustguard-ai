# TrustGuard AI — Cyber-Intelligence Forensic Command Center
**Tagline:** *Detect. Block. Trace. Protect.*

## 🛡️ Getting Started

The dashboard is served locally at:
👉 **`http://localhost:8080/`**

Or you can directly open:
👉 `index.html` in any web browser.

### Project Structure
- `index.html` — Cyber command center with all 5 integrated views.
- `css/style.css` — High-contrast glassmorphism, cybernetic scanlines, HUD components, and print stylesheets.
- `js/app.js` — Interactive routing, audio spectrogram canvas, video frame scrubber, split slider diff, and Hugging Face model sliders.
- `assets/` — Forensic evidence specimens, neural artifact heatmaps, and archive comparison matches.
